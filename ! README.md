# Linux-Setup
Setting up Ubuntu Linux in a virtual machine. In this project, I install VirtualBox to run my VM from. I install an Ubuntu ISO and setup and configure from start to finish.
I also use the terminal to install tools, update and upgrade packages, as well as enabling SSH via the terminal.

Lastly, to show my project and my skills with documentation, I used screenshots and created an SOP as a walkthrough of the project.
